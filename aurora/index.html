    How playback works
    • Direct URLs & local files play in AURORA with full controls and real-time visualization (when the server allows CORS).
    • YouTube plays through the official YouTube player. Some videos block embedding.
    • Spotify plays through the official Spotify embed. Full tracks need a Spotify login in the embed; otherwise previews play. Spotify's audio is never exposed to AURORA.
    • No link handy? (a short synthetic sound, handy for trying the visualizer).

    About the limits

    • Real frequency analysis works for local files and direct URLs whose server sends CORS headers.
    • YouTube and Spotify embeds never expose audio to web pages, so AURORA shows a clearly labelled ambient visual for them instead.
    • AURORA never downloads, proxies or decrypts YouTube/Spotify streams.
